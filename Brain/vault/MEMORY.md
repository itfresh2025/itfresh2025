## Learnings

### What Worked
- Process goals как recurring tasks в Todoist — держат фокус на привычках

### Rules to Remember
- Dailies могут содержать только тест-сообщения — не создавать задачи из "Привет"
- MCP tools mcp__todoist__* работают напрямую (подтверждено). Приоритеты: строки "p1"/"p2"/"p3"/"p4" (не числа)
- Todoist dueString "this week"/"this month" → HTTP 400. Использовать "next monday" или ISO дату
- Health protocol настроен: [[thoughts/health/supplements-schedule]] — схема добавок февраль 2026
- Алкоголь 07.03.2026: 2 бутылки вина → нарушение ONE Big Thing недели. При алкоголе: B1 (критично!) + NAC + Расторопша обязательны
