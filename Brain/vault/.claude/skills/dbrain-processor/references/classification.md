# Entry Classification

## Work Domains → Categories

Based on user's work context (see [about.md](about.md)):

### Client Work (IT-аутсорсинг)
Задачи по клиентам, инциденты, выезды, поддержка, администрирование

**Keywords:** клиент, компания, сервер, сеть, Windows, 1С, почта, хостинг, терминал, Евгений, Кирилл, выезд, инцидент, не работает, сломалось, настроить, установить

**→ Category:** task (p1-p2) → Todoist

### Финансы
Доходы, расходы, платежи, ипотека, кредит, стройка, счета

**Keywords:** деньги, оплата, счёт, ипотека, кредит, машина, стройка, расход, доход, перевод, банк, млн, тыс руб

**→ Category:** task (p2-p3) → Todoist + запись в thoughts/

### Команда
Задачи для Евгения и Кирилла, координация, найм

**Keywords:** Евгений, Кирилл, инженер, поставить задачу, отправить, съездить, проверить у клиента

**→ Category:** task (p2) → Todoist

### Продажи / Новые клиенты
Лиды, переговоры, предложения, рассылки

**Keywords:** новый клиент, лид, переговоры, КП, предложение, рассылка, сарафан, позвонить потенциальному

**→ Category:** task (p2) + project → thoughts/projects/

### Здоровье и спорт
Зал, вес, питание, сон, давление, алкоголь

**Keywords:** зал, тренировка, вес, давление, сон, выпил, не пил, питание, здоровье, врач

**→ Category:** task (p2-p3) → Todoist + reflection если инсайт

### Личное и семья
Семья, дети, отношения, дом, переезд

**Keywords:** Ольга, Серафима, Мирослав, сын, дочь, дом, Геленджик, стройка, переезд, Виктория, отношения, выбрать, определиться

**→ Category:** reflection или task в зависимости от контекста

### Расписание и напоминания
Встречи, звонки, дедлайны, напоминалки

**Keywords:** напомни, не забыть, встреча, звонок, в X часов, завтра, на неделе, дедлайн, срочно

**→ Category:** task → Todoist с датой/временем

### Идеи и развитие
Мысли об улучшении бизнеса, автоматизации, новых направлениях

**Keywords:** идея, хочу попробовать, а что если, можно автоматизировать, новое направление, думаю о

**→ Category:** idea → thoughts/ideas/

## Decision Tree

```
Entry text contains...
│
├─ Клиент/инцидент/техническая проблема? ────────> TASK (p1-p2)
│
├─ Финансы/платёж/кредит/стройка? ──────────────> TASK (p2-p3)
│
├─ Для Евгения или Кирилла? ─────────────────────> TASK (p2)
│
├─ Новый клиент/продажи? ────────────────────────> TASK (p2) + PROJECT
│
├─ Здоровье/зал/вес/алкоголь? ───────────────────> TASK (p2-p3) или REFLECTION
│
├─ Семья/отношения/дом? ─────────────────────────> REFLECTION или TASK
│
├─ Напоминание/встреча/звонок? ──────────────────> TASK с датой
│
└─ Идея/мысль об улучшении? ─────────────────────> IDEA
```

## Приоритеты Todoist

| Приоритет | Когда |
|-----------|-------|
| p1 | Срочный инцидент у клиента, критично |
| p2 | Важная задача с дедлайном |
| p3 | Плановая задача |
| p4 | Когда-нибудь / идея |
